# Data behind the research log

Each folder holds the raw tables for one entry of [`docs/FINDINGS.md`](../docs/FINDINGS.md), one row per
seeded world, exactly as `tools/experiment.js` (or the Lab page) wrote them. The lines starting with `#` at
the top of each file record the version, commit and settings used, so every file can be re-made by running
the same command on the same commit.

Entries 1–7 were measured before raw tables were kept; their numbers are in the log, and each can be
re-run with the command or the Lab link given there.

The columns are explained in `README.md` ("For researchers"). Released under the MIT licence with the rest
of Genesis; please cite Genesis as in `CITATION.cff`.
