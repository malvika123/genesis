Experiment

Each world is built from its seed and these settings and nothing else, so the same seed and settings on the same version give the same world. To test one feature, compare two setups that differ only in that feature, on the same seeds. This page runs the same code as the command-line runner (tools/experiment.js), in the background, one world per core.

Running

Keep this tab open; worlds run only while it is open. Each tile is one world: its seed, and how many people are alive when it ends.

Reading the results

        

          Worlds differ a lot from seed to seed, so a small difference between A and B can be chance. The
          range shown with each difference (the mean ± about two standard errors) is where the true difference
          probably lies; if it includes zero, the setups cannot be told apart with this many worlds. Run more
          seeds to narrow it. Results from the project's own tests are written up in the
          research log.
