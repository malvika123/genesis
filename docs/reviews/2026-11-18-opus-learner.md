# Opus on the learner's chain and memory limit (18 Nov 2026) — read only; ran nothing

**Verdict: do not change the learner yet. Fix the probe first.** The 2–3 act ceiling is mostly an artefact of how the probe's task is built, so it cannot yet be compared with chimpanzees.

**Three causes found in the code.**
(a) **The probe's chain fights the inborn hand reflexes (the biggest cause; an artefact).** The chain shows "where you are" on the hand senses `IB+19+k` (`chain-probe.js` line 88). Those inputs carry inborn weights (`brain.js` lines 104–136) copied from the genes: state 0 "holding a stone" (`IB+19`) asks for TAKE, which has an
inborn weight of **−4** there (do not pick up while holding) and STRIKE +0.9 (TAKE starts at about 0.2% a step, a hand estimate, not run); state 2 asks for EAT, the always-on input (`IB+11`) gives EAT −2.5 and STRIKE still competes (about 1% a step); states 3 and 4 are the "stone/stick underfoot" inputs (`IB+22/23`) where TAKE gets +1.6, competing with GIVE and CLIMB.
Each extra act costs a different amount set by the reflexes, so chain length is mixed up with which acts and inputs were picked; the delay task has the same problem (the "now" signal `IB+23` pushes TAKE; cue 0 sits on `IB+19`). These biases sit on the direct senses→choices path, so no number of thinking units removes them: that alone can explain "same at every size".
(b) **Size is cancelled by design.** `learnStep` and `replayOne` scale every thinking-unit connection by `k = min(1, S.nh/nh)`, `S.nh = 16`: 0.84 at 19 units and **0.25 at 64**; the value estimate comes only from thinking units (`OV`), so its total step stays the same at every size; each unit's own input weights learn up to 4× slower. This rule is ours, with no source; stability gives a reason to scale the readout, not the input weights.
(c) **Short-term memory does not grow, and the memory region plays no part.** The echo is always units 0–7 (`sim.js` line 520, `NM = 8`) whatever the size or layout; units 0–2 are fear, memory and sound and do not hear the cue inputs, so only general units 3–7 can carry the cue; the echo is credited one step back only; at 64 units the same loop learns 4× slower: why cue holding is slightly worse. The inherited `g.lay` "memory" region only changes which inputs a unit listens to: **the owner's pathway (inherit a better memory) is cut off in today's code.**
So "size cannot pay" is true for the code as written, but by construction ((b) and (c)), not as a discovery.

**Smallest honest changes, in order.** (1) **Probe only, world untouched:** put the chain states on neutral inputs (or remove the inborn hand weights inside the probe), give each brain a random assignment of acts, report each step's starting choice probability; if chains then reach 4–5 at 19 units, the learner is at chimpanzee level and needs no fix; nothing to source (it removes a confound). (2) **The `k` scaling as a registered assumption with two ends:** `S.nh/nh` (no gain from size, today) and `1` (gain from size); neither end is sourced: register both, report both, do not choose by outcome. (3) **Echo from the memory region:** the echo comes from the inherited memory units, so capacity can vary, be inherited and be selected; partly supported: Hopkins, Russell & Schaeffer 2014 (*Curr Biol*, 99 Yerkes chimpanzees: the spatial-cognition component incl. spatial memory significantly heritable; no primate heritability figure for working memory as such); the mechanism is ours; guard: founders' default layout must give the same echo as today's (8 units), so a small-brained ape-like hominin stays where it is. (4) **Relating a step to seconds:** dopamine credit at a synapse lasts about 0.3–2 s (Yagishita et al. 2014, *Science* 345:1616); a 15-minute step is a different thing altogether: note in ASSUMPTIONS.md, do not fix now (a sub-step model is a big change). **Do not change the credit rule itself** (traces, backward replay over 16 steps): no credit defect shown; a chain of 4–5 fits inside the replay window; the bottleneck is exploration against the reflexes.

**Fair test.** Prediction first; one change at a time; paired seeds, 4 sizes, **at least 20 brains a size** (10 cannot separate 6/10 from 4/10). **The gate:** at 19 units every change must keep chain length within the chimpanzee range (no more than about 5) and cue holding no better than today; reject any change that lifts small brains above that. A fair "brain pays" result needs: the effect at both ends of `k` (or at least the size-neutral end); monotonic across sizes; survives the randomised act assignment; comes from units the genes can vary. If it still does not pay: "for this kind of learner, extra units buy nothing on these tasks" stands as a result; next come richer tasks where capacity plausibly matters; do not tune the learner until size pays.

**Would not:** remove the inborn hand reflexes in the world (realistic; the probe misuses them); set `k = 1` alone (builds in a size advantage); map units to chain length or to the chimpanzee 4–5 (Kawai & Matsuzawa's 4–5 numerals were trained step-by-step lab tasks, not reward only at the end: not like-for-like); raise `NM` across the board; start relay runs before steps 1–3.

**The owner should decide two things:** whether `k` becomes a registered two-ended assumption (an invented rule that currently forbids any gain from size); whether short-term memory should be tied to the inherited memory region (a new mechanism of ours, supported only indirectly). Step 1 needs no decision. **Could not verify:** primate working-memory heritability; any study linking cue-holding length to brain size; the per-step choice probabilities are hand estimates. Entries 87 and 107 should carry a note that the chain probe is confounded by inborn hand reflexes.
